# Responsive portal navigation

## Goal
Make the employee portal navigation clearly show the current section and provide layouts tailored to desktop, tablet, and mobile screens.

## Changes
- Use a fixed bottom navigation on phones with compact icons and short labels.
- Use a scroll-safe horizontal navigation strip on tablets with full section labels.
- Use a spacious website navigation bar on desktops, including longer labels and the profile control aligned separately.
- Give every active section a strong, consistent selected state with color, contrast, and a position indicator.
- Preserve role-based visibility for Administration and the unread message counter.
- Keep the selected section reflected in the page URL so navigation state remains clear.

## Validation
- Check the portal at mobile, tablet, and desktop widths.
- Confirm every navigation control opens its existing section without changing permissions or functionality.
- Confirm labels, badges, and active indicators remain readable and do not overlap.
